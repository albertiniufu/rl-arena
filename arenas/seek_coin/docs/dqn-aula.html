fundamentos · observação, ação e Q

A rede devolve um valor por ação

A observação é a grade semântica (5, 20, 32) (ou um vetor (N,) nas outras arenas). A saída é o Q estimado de cada uma das seis ações.

fundamentos · a equação de Bellman

Q-learning com uma rede

O DQN aproxima a função de valor-ação ótima. O alvo de cada transição é o retorno imediato mais o melhor Q do próximo estado, descontado — e só o terminal verdadeiro corta o bootstrap.

y = r + γ · (1 − terminal) · maxa′ Qalvo(s′, a′)
L(θ) = SmoothL1( Qonline(s, a) , y )

Por que uma rede-alvo?

Se o alvo usasse a mesma rede que está sendo atualizada, perseguiríamos um alvo móvel: cada passo mudaria os dois lados da equação. A target é uma cópia congelada, sincronizada duro a cada C = 1000 updates bem-sucedidos.

Por que SmoothL1?

O Huber loss é quadrático perto de zero e linear longe dele: menos sensível a outliers de TD do que o MSE, o que estabiliza o alvo quando a rede ainda está errada. O gradiente é clipado em norma 10.

algs/alg_dqn/agent.py — alvo de TD
def td_target(reward, next_q, terminated, gamma):
    # terminado de verdade zera o futuro;
    # truncamento por tempo continua bootstrapping
    return reward + gamma * (1.0 - terminated) * next_q
→Truncar ≠ terminar. O replay guarda apenas terminated. Um episódio que acaba por tempo não é um estado terminal: o valor do futuro ainda existe e o alvo continua bootstrapping.
CC = 1000 é empírico. O comentário do código registra a busca: com a rampa de ε e --learn-every 4, C=1000 coletou 15,8 moedas de treino contra 8,8 do C=10.
memória · replay

Replay uniforme: quebrar a correlação

Transições consecutivas são altamente correlacionadas. O replay guarda as últimas 50 mil e sorteia um lote com chance igual, embaralhando a ordem em que a rede aprende.

algs/alg_dqn/replay_buffer.py
class ReplayBuffer:
    accepts_masks = True

    def add(self, state, action, reward, next_state,
            terminated, next_mask=None):
        self.data.append((state, action, reward,
                          next_state, terminated))
        # risk: máscara do próximo estado para não
        # superestimar ações inválidas no alvo
        self.masks.append(next_mask)

    def sample(self, batch_size):

        idxs = random.sample(range(len(data)), batch_size)

  • Capacidade. 50 mil transições (--buffer-size no CLI). Passou disso, a mais antiga sai.
  • Uniformidade. Toda transição tem a mesma probabilidade. Não há prioridade — isso é o que o Double DQN/PER adiciona no outro pacote.
  • Máscaras. No risk, ações ilegais no próximo estado recebem −inf antes do max; se não sobrar ação legal, o próximo valor é zero.
  • Cópia por amostragem. list(self.data) custa memória temporária, mas o buffer cheio é indexado em O(1).
    • ΣOff-policy. Como o replay guarda dados de políticas antigas, o DQN pode reaproveitar cada transição muitas vezes. É o oposto do PPO/A2C, que descartam o rollout após o update.
    exploração · ε-greedy

    Explorar com probabilidade ε

    Com probabilidade ε a ação é sorteada uniformemente; caso contrário, é o argmax dos Q-valores. No treino o ε cai ao longo do tempo; na avaliação é sempre 0 (guloso).

    def act(self, state, greedy=False, action_mask=None):
    if not greedy and random.random() < self.epsilon:
        return random.randrange(self.n_actions)   # explora
    q = self.online(x)
    if mask is not None:
        q = q.masked_fill(~mask, float("-inf"))  # risk
    return int(q.argmax(dim=1).item())            # explota

    Quem agenda o ε?

    O agente tem um decay por passo (epsilon ×= 0,9995 até 0,05). Mas o train.py assume o controle por padrão: --epsilon-ramp-episodes 150 faz uma rampa linear de 1,0 até --epsilon-min 0,1, contada em episódios absolutos (para a retomada continuar de onde parou).

    Por que uniforme?

    Simples e sem viés preferencial entre ações: a exploração não depende dos Q-valores atuais. O custo é desperdiçar passos em ações obviamente ruins no começo — e, no nível 2, em patches de areia/gelo que exigem uma política mais fina.

    !Lote vetorizado. act_batch aplica ε-greedy linha a linha e respeita a máscara; é o caminho usado por --envs > 1.
    update · um learn()

    O update, passo a passo

    1. Espera. if len(buffer) < max(warmup, batch_size): return None. O warmup padrão do CLI é 1000.
    2. Amostra batch_size (64 por padrão) transições uniformemente, com máscara se o buffer tiver.
    3. Q atual: q = online(s).gather(1, a) — só o valor da ação tomada.
    4. Alvo: max target(ns), mascarado, e y = r + γ(1−terminal)·maxQ′ sob no_grad.
    5. Perda: SmoothL1(q, y); backward; gradiente clipado em norma 10 antes do passo do Adam.
    6. Contadores: steps += 1, ε decai; a cada C updates a target recebe uma cópia dura da online.
    # resumo do miolo de learn()
q = self.online(s).gather(1, a).squeeze(1)
with torch.no_grad():
    next_q = self.target(ns).max(dim=1).values
    target = td_target(r, next_q, term, self.gamma)
loss = self.loss_fn(q, target)

if self.steps % self.C == 0:
    self.target.load_state_dict(self.online.state_dict())
    1Um update por chamada. O treino padrão chama learn() a cada 4 transições (--learn-every 4) com um ambiente. Cada chamada consome um batch novo.
    2Sem gradiente no alvo. O alvo é tratado como constante; só Q(s, a) recebe gradiente. Sem o no_grad, a target também seria treinada.
    3Retomada. O checkpoint guarda online, target, otimizador, steps, epsilon e gamma — o replay não é salvo, então a retomada não é bit a bit.

    Como o treino, a avaliação e o play usam o DQN

    Loop por passo: act → env.step → buffer.add → a cada K passos learn. O ε é recalculado por episódio absoluto. --envs > 1 usa act_batch.

    fechamento · trade-offs

    Quando o DQN basta — e quando não

    Ganha

    Simplicidade e reuso de dados. Um update custa um batch do replay, e cada transição pode ser aprendida muitas vezes. É a melhor referência para comparar as variantes.

    Limita

    O max do alvo superestima valores com ruído (o Double DQN corrige), o replay uniforme ignora transições raras ou valiosas (o PER corrige) e uma cabeça única mistura V e A quando as ações são parecidas (o dueling corrige).

    →Para levar. DQN = Q-learning + rede + replay + target. O alvo é r + γ(1−terminal)max Q′; o replay quebra a correlação; a target estabiliza; ε-greedy explora.
    !O nível 2 muda o jogo. Areia (efeito de 5 s após sair) e gelo (escorregão) quebram a suposição de dinâmica estacionária. O DQN aprende, mas a política reativa com ε alto erra com frequência no começo — por isso a comparação com EPPO/AES/GTR no mesmo protocolo.
